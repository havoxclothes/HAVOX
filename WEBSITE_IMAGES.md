# HAVOX Website Images

Use this file to choose the images used by the website. You can edit the filenames below directly in GitHub.

## 1. COVER IMAGE

**File:** `assets/REPLACE_WITH_COVER_IMAGE_FILENAME`

Replace the filename above with the exact filename of the image you want as the HAVOX cover/hero image.

Example:
`assets/5. HAVOX cover.png`

---

## 2. BACKGROUND IMAGE

**File:** `assets/REPLACE_WITH_BACKGROUND_IMAGE_FILENAME`

Replace the filename above with the exact filename of the image you want as the main HAVOX website background.

Example:
`assets/4. HAVOX background.png`

---

## 3. HOW TO CHANGE THEM

1. Upload your chosen images into the repository's `assets` folder.
2. Copy the exact filename, including spaces and `.png` / `.jpg`.
3. Replace the filename after `assets/` above.
4. Commit the changes.
5. Tell ChatGPT **"I updated WEBSITE_IMAGES.md"** and the website can be updated to use your choices.

**Important:** Do not rename or delete the image files unless you also update the filenames in this file.
